Dit is het nieuwe design voor de webst van Visual Thinking. De opdrachtgeever is Charley Muhren. De website bestaat uit 2 pagina's: home en tekenmethodes. Ik moest mij focussen op de tekenmethodes pagina waardoor ik deze als  Op de website kunnen studenten en docenten leren om hun gedachten en doelen te verbeelden. De website is responsive en eerst gemaakt en ontwerpen op desktop en daarna voor mobile.

Hier staat de website: https://ayalefevere.github.io/the-client-website/
